# 06. UI Layout System — 프롬프트 전시실 & 동적 레이아웃

## 컨셉: "전시실(Gallery)"

메인 화면은 미술관/전시실처럼 프롬프트와 그 결과물을 "작품"으로 전시하는 형태.
Phase 1에서는 이 전시실 자체가 메인 화면 전부지만, 구조적으로는 **여러 모듈이 각자의 "전시관"을 갖고 이 화면에 얹히는 구조**로 설계한다.

## 레이아웃 슬롯 구조

```
┌─────────────────────────────────────────────┐
│  Header: 로고 / 검색 / 언어 / 다크모드 / 로그인   │
├─────────────────────────────────────────────┤
│  [ hero slot ]  ← Phase별로 교체 가능한 대표 모듈  │
│  Phase 1: 오늘의 베스트 프롬프트 캐러셀            │
├───────────────────────────────┬─────────────┤
│  [ feed slot ]                │ [ sidebar ]  │
│  - 신규 등록 프롬프트           │  - NEW 모듈   │
│  - (Phase2 활성화시) 모델비교   │    배너 카드  │
│    결과물이 같은 피드에 섞여 노출 │  - 랭킹      │
│  - (Phase3 활성화시) 파이프라인  │  - 공지      │
│    산출물도 같은 피드 카드 형태로 │             │
│    자연 편입                    │             │
└───────────────────────────────┴─────────────┘
```

- `hero`, `feed`, `sidebar`는 `docs/02`의 `mainScreenSlot` 값과 1:1 매칭
- 렌더링 시 `modules` 테이블을 조회해 `enabled=true`인 것만, `nav_order` 순으로 슬롯에 채운다
- 새 모듈이 `feed` 슬롯에 등록되면 **기존 피드 카드와 같은 그리드에 자연스럽게 섞여 들어간다** — 카드 컴포넌트는 `artifacts.type`에 따라 다른 미리보기 렌더러를 쓰지만(이미지/영상/3D/게임), 카드 자체의 레이아웃(제목, 작성자, 좋아요, 태그)은 공통 컴포넌트 사용

## "NEW 모듈 자동 노출" 흐름

1. 개발팀이 새 모듈(예: Phase 3의 3D 파이프라인)을 완성
2. 어드민 화면에서 해당 모듈을 `enabled: true`로 전환, `status: 'new'`, `new_until`을 2주 뒤로 설정
3. 배포 즉시 메인 화면 상단 `sidebar`에 "NEW: 3D 에셋 만들어보기" 배너 자동 등장 (코드 재배포·레이아웃 수정 불필요)
4. `new_until` 경과 후 배지 자동 소멸, 모듈은 `feed`/`hero` 등 정규 위치로 편입

## 네비게이션 바

- 데스크톱: 상단 가로 메뉴, `modules` 레지스트리를 좌→우 `nav_order`대로 렌더링
- 모바일: 하단 탭바 (최대 4~5개 노출, 나머지는 "더보기")
- Phase가 늘어나 모듈이 많아지면 카테고리 드롭다운으로 자동 그룹핑 (`phase` 값 기준 그룹)

## 다크모드 / 라이트모드

- `next-themes` 사용, 기본값은 시스템 설정 감지, 헤더에 토글 스위치 상시 노출
- 테마 토큰은 Tailwind CSS 변수로 정의 (`--bg`, `--fg`, `--card`, `--accent` 등), 컴포넌트는 시맨틱 토큰만 참조 — 하드코딩된 색상 클래스 금지
- 이미지/영상 카드의 배경은 테마와 무관하게 콘텐츠 원본 유지, 카드 프레임만 테마 반응

## 다국어 (레이아웃 관점)

- 모든 텍스트는 `next-intl` 메시지 키로 관리, `modules.title_ko`/`title_en`처럼 DB에 저장된 텍스트도 로케일별 컬럼 또는 JSONB로 분리
- 레이아웃 자체는 LTR 고정 (RTL 언어는 로드맵 외 — 필요 시 별도 검토)

## 반응형 우선순위

1. 모바일 퍼스트로 카드 그리드 설계 (1열 → 태블릿 2열 → 데스크톱 3~4열)
2. `hero` 슬롯은 모바일에서 세로 스크롤 캐러셀로 축소
3. 실행 엔진이 필요한 콘텐츠(게임, 3D뷰어)는 모바일에서 카드 클릭 시 전체화면 모달로 전환

## 어드민 모드 UI

- `/admin` 라우트 그룹, 일반 사용자 화면과 완전히 분리된 레이아웃
- 핵심 화면: 모듈 on/off 스위치 보드, 콘텐츠 심사 큐, 사용자 관리, 스모크테스트 리포트 승인
- 상세 권한 구조는 `docs/08-i18n-auth-admin-theme.md` 참조
