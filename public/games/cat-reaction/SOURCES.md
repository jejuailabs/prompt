# 제작 출처

게임 규칙·화면·효과·효과음은 자체 코드입니다. 3D 냥이 모델 코드(cats.mjs·breeds.mjs·scene.mjs)는 이 프로젝트의 냥이 클럽 패키지(cat-sling 1.0.0)에서 복사했고 반응속도용 표정(sleepy·ready·dizzy)을 추가했습니다. Three.js 0.172.0 MIT 라이선스는 vendor/THREE-LICENSE.txt, 폰트 출처·해시·라이선스는 fonts/ 폴더에 있습니다. 물고기·번개 아이콘은 인라인 SVG로 직접 그렸습니다. cover.png는 실제 게임 화면을 캡처한 이미지입니다.
