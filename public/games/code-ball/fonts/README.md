# Game typography
Pretendard Variable: Korean UI, controls, legible tabular scores (100–900).
Fredoka variable: playful Latin game titles (300–700).
Cinzel variable: premium blackjack titles and court-card lettering (400–900).
Korean display text falls back to Pretendard because the two Latin families do not cover Hangul.

All three are unmodified self-hosted upstream files under SIL OFL 1.1; their complete license notices accompany them. sources.json records the downloaded URL, date, byte size and SHA-256. No runtime Google Fonts/CDN request is required.
