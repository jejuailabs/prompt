# 냥이 합치기 / Purrfect Merge

통통한 냥이들이 서로 밀리고 구르며 골골! 같은 품종을 만나게 해 커다란 친구로 합체해요. 연쇄 합체를 만들고 상자가 넘치기 전에 최고 기록에 도전해요.

드래그 후 손 떼기 / 좌우 방향키·스페이스 = 조준·낙하

정적 HTTP(S) 서버에 폴더 전체를 배치하고 index.html을 엽니다. 상대 경로이며 로그인·CDN·API 없이 실행합니다. 엔진·캐릭터·7종 PNG·서체·라이선스·실제 썸네일을 포함합니다. 진행 속도는 단계에 따라 증가하고 사용자 배율은 1–2배만 허용합니다. 게임별 최고 점수·한 판 종료·일시정지·재시작을 지원합니다. parentOrigin/source/origin/gameId를 검증하는 호스트 계약 v1입니다. start/pause/resume/restart/resize/dispose, game-ready/start/score/finished 및 roundId/durationMs를 사용합니다. qa=1/preview=1은 온라인 제출을 하지 않습니다. 종료 시 입력·오디오·GPU·관찰자를 해제합니다. 재패키징: node scripts/package-cat-playground.cjs
