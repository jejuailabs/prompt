## 관리자 등록 · 수정 (2026-10-07)

- 관리자 로그인 → AI 일정 → 일정 등록. 제목·분류·주최·소개·일정 안내·신청/안내 링크를 입력한다.
- 포스터 이미지 선택: PNG/JPEG/WebP, 3MB 이하. 서버에서 이미지 디코딩 및 WebP 변환 후 기존 uploads 버킷의 ai-events/{ownerId}/ 경로에 저장한다. 원본 메타데이터를 제거하고 최대 1800×2400 범위로 줄이며 전체 이미지를 표시한다.
- 이미지가 없으면 제목 또는 최대 4줄의 포스터 문구와 색상으로 포스터를 만든다. 접수 시작·마감 및 일정 시작·종료 시간은 확정된 경우만 한국시간으로 입력한다.
- 저장은 기존 Artifact(type=text, sourceModule=ai-events, visibility=unlisted)와 metadata.aiEvent를 사용한다. 별도 테이블/스키마 변경이나 유료 생성은 없다.
- 기본 공개 목록에서 등록된 게시물과 초기 6개가 함께 보인다. 초기 ID를 유지한 저장본이 있으면 초기 정보 대신 저장본이 표시된다.
- 일정 관리에서 숨김도 함께 조회한다. 숨기기는 archived 상태로 바꾸며 이미지와 입력 정보를 보존한다. 다시 공개로 복원할 수 있다.
- 전용 API와 일반 Artifact 작성 API 모두 관리자 역할을 서버의 인증된 프로필로 확인한다. 일반 회원은 본인 소유 Artifact라도 AI 일정으로 등록·수정·삭제할 수 없다.
- 개발 디자인 미리보기는 폼과 로컬 파일 미리보기만 제공한다. 관리자 계정으로 위장하지 않으며 DB·Storage에 쓰지 않는다.
