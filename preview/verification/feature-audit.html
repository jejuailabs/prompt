01 / 화면과 사용자 흐름

기능판정직접 확인한 범위와 한계
홈 리본동작 확인모션 일시정지, 다음 버튼, 마우스 드래그에 따라 선택 작품이 바뀜. 바로 경험하기 → 해당 작품 상세. 전체 애니메이션 품질의 최종 디자인 승인과는 별개.
갤러리동작 확인이미지 필터 5개 → “음식” 검색 1개 → 상세 이동. 작품 이미지 로드 및 공유 URL 클립보드 확인.
프롬프트 위키수정·확인직접 주소/새로고침 복원. 실제 이미지와 6개 원본·1개 포크 표시. 상세 본문, 2,954자 복사, 연결 결과물 1개 확인. 버전 이력·댓글·포크 저장은 운영 검증 필요.
게임룸시작 확인벽돌깨기·네온 퐁·헬리 대쉬·스네이크·테트리스·플래피·슈터 7개. 나머지 6개도 각각 시작 버튼을 눌러 게임 HUD 진입 확인. 벽돌깨기 점수 30은 직전 검사에서 확인. 각 게임의 모든 조작·승패 조건은 완주 검사하지 않음.
게임 점수·랭킹운영 미검증미리보기는 플레이/점수/광고 기록을 저장하지 않음. 랭킹 스냅샷이 없어 비어 있음. 등록·수정·삭제·좋아요 실저장은 미검증.
메뉴수정·확인전체 메뉴의 QR 클릭 → QR 개별 화면 확인. 모바일·사이드바도 같은 목적지 함수 사용. 자동 검사로 모든 도구 목적지 및 파이프라인 ID 전달 확인.
모바일선택 화면 확인위키·상세·TTS 가로 넘침 없음. 게임룸·홈은 직전 검사에서 확인. 390×844 기기 설정, 브라우저 보고 CSS 폭 358px. 모든 화면·모든 기기 크기 검증을 의미하지 않음.
바이브코딩 가이드동작 확인Git 사용자 입력에 테스트 아이디와 이메일을 넣고 명령 전체 복사 확인. VS Code 터미널 안내 확인. 해당 명령을 실제 PC에서 실행하지 않음.
커뮤니티부분 확인공개 프롬프트/작품 랭킹 연결. 도움 요청 조회 실패를 빈 목록과 구분하고 등록·답변·해결 저장 오류 안내 추가. 실제 작성·답변 저장은 미검증.
모델 실험실생성 미검증현재 공급 모델 없음. 미리보기 안내·로그인 경계 및 모델 조회 오류 처리. 실제 비교 생성·결과 저장·차감은 미검증.
영상 스튜디오입력 흐름 확인새 프로젝트 → 텍스트/이미지 입력 모드 → 생성 시 로그인 안내 확인. 실제 영상이 없는 스냅샷이므로 공개 영상 목록은 비어 있음. 실제 렌더·편집·취소·파일 수신은 미검증.
3D 스튜디오목록 수정실제 파일 없는 예시를 공개 에셋으로 표시하던 문제 제거. 공개 작품 API와 실제 내 프로젝트 목록 사용. 스냅샷에 3D 없음. 생성·모델 뷰어·리깅·다운로드 실검증 필요.
로그인·내 프로젝트·수익운영 미검증비로그인 안내 확인. 미리보기의 실행 불가 로그인 버튼 비활성화. 실제 OAuth, 가입 크레딧, 사용자별 저장·소유권·정산 데이터는 미검증.
가이드·관리자·마켓·파이프라인·스모크미리보기 연결 없음API 연결 없는 화면에 명시적 안내를 표시. 이 안내는 기능 완성이 아님. 운영 데이터/권한으로 별도 검증 필요.
MCP 연결실연결 미검증화면·설치 안내 확인. 연결 실패 처리와 미리보기 버튼 상태, 최초 렌더 불일치 수정. 운영 DB 적용·키 발급/해제·Codex/Claude Code에서 GPU 결과 수신 검증 필요.
광고·결제운영 미검증광고 자리 및 설정형 로더가 있는 상태. 실제 AdSense 송출/승인, 결제·환불·정산은 확인하지 않음.

03 / 배포 전에 남은 일

  1. 인증·저장: 운영 테스트 계정으로 로그인/가입 보너스, 업로드, 프롬프트 포크, 댓글·좋아요, 프로젝트 저장·삭제와 권한 확인.
  2. 과금: 이번에 11개 AI API의 로그인 검사를 추가했지만, 전체 도구 크레딧 예약·차감·실패 환불 규칙은 아직 통일되지 않음.
  3. 생성: 영상·3D·음악과 개별 AI 도구에서 실제 공급자 연결 후 생성→상태 조회→결과 재생/다운로드→취소/실패 복구 검증.
  4. MCP: DB 적용과 실제 연결 키 발급, 클라이언트에서 생성·진행 조회·결과 수신 검증.
  5. 미완성 기능: 자동 컷편집 렌더, AI 게임 생성, URL 단축, 뉴스·팁·스킬 전용 작성/분류.
  6. 운영 기능: 관리자·마켓·결제·정산·실제 광고 연결 검증.
검증 한계

자동 검사 52개 중 51개 통과, 실제 3D 결과 파일을 요구하는 기존 검사 1개 건너뜀. API 인증 회귀 검사는 모의 응답을 사용했습니다. 실제 OAuth, 공급자 생성, 과금, DB 저장 성공의 증거가 아닙니다. DB 변경·유료 생성·배포는 수행하지 않았습니다.
