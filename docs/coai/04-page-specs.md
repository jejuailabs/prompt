# 04. 페이지 상세 명세

> 공통 규칙
> - 모든 목록 페이지에는 **목록형 ↔ 카드형 보기 전환**(`ViewToggle`)과 정렬(최신순 / 인기순 / 댓글순)이 있습니다.
> - 모든 상세 페이지 하단에는 좋아요, 저장, 공유, 신고 버튼과 댓글이 있습니다.
> - 빈 목록은 `EmptyState`로 "첫 글을 올려주세요" 같은 행동 유도 문구를 보여줍니다.
> - 페이지네이션: PC는 번호형(게시판 감성), 모바일은 "더 보기" 버튼. 무한 스크롤은 쓰지 않습니다.

## 2. 뉴스·이벤트 `/news`
상단 탭: **뉴스 | 행사·모임**

### 뉴스
- 목록: `NewsItem` 가로형. 필터: 전체 / 국내 / 해외 / 서비스 업데이트 / 정책
- 상세: 제목, 출처(원문 링크 필수), 대표 이미지, **3줄 요약**, 본문(운영진 해설), "이게 나한테 무슨 의미?" 박스, 관련 가이드 링크, 댓글
- 원문 기사 전문을 그대로 옮겨 싣지 않습니다. 요약 + 해설 + 원문 링크 형식을 지킵니다(저작권).

### 행사·모임
- 목록: 세로형 `PosterCard`(sm) 갤러리, PC 4열 / 모바일 2열
- 필터: 세미나 / 스터디 / 교육 / 모임, 상태: 모집중 / 마감 / 종료
- 카드 위 배지: 상태(모집중 초록, 마감 회색), 날짜 D-day
- 상세: 포스터 큰 이미지 + 오른쪽(모바일은 아래) 정보 패널
  - 일시, 장소(지도 링크), 정원 / 현재 신청 수, 참가비, 주최, 준비물
  - **신청 버튼**: 1단계는 외부 링크(당근 모임, 구글폼)로 이동. 2단계에서 자체 신청(회원 로그인 → 신청 목록 관리) 검토
  - 스터디 행사는 "스터디방 바로가기"로 `/learn/study/[id]`와 연결
- 지난 행사는 "후기" 탭에서 커뮤니티 후기 글을 모아 보여줍니다.

## 3. 프롬프트 `/prompts`
- **결과물 먼저 보기** 갤러리: 이미지·영상 결과물이 카드 위쪽을 크게 차지하는 Masonry(벽돌형) 배치 (PC 4열, 모바일 2열)
- 카테고리: 이미지 / 영상 / 업무 / 글쓰기 / 코딩 / 기타. 추가 필터: 사용한 AI 서비스(ChatGPT, Claude, Midjourney …)
- 카드: 결과물 썸네일 → 카테고리 태그 → 제목 → 작성자·등급 → 좋아요, 저장, 복사 수
- 상세
  - 결과물(여러 장이면 슬라이드)
  - **프롬프트 본문 박스 + 큰 "복사하기" 버튼** (복사 수 집계)
  - 사용한 서비스 / 모델 / 설정값 (예: 비율, 스타일)
  - 변수 표시: `{주제}`처럼 중괄호 안의 단어는 강조 표시, "내 값으로 채우기" 입력칸 제공
  - 라이선스: 결과물의 상업적 이용 가능 여부 (작성자가 선택)
  - "따라 만들기(리믹스)" 버튼 → 원본을 연결한 채로 새 프롬프트 작성
  - 스터디 과제로 올린 경우 "○○ 스터디 3회차 과제" 배지
- 작성 `/prompts/new`: 결과물 업로드(이미지 최대 10장, 영상 1개 최대 50MB), 프롬프트, 서비스, 카테고리, 태그, 라이선스

## 4. 만들어보기 `/make`
- 유형 탭: **모션그래픽 / AI 게임 / 바이브코딩 / 랜딩페이지**
- 카드: 썸네일(GIF 또는 영상 미리보기, 마우스를 올리면 재생) + ▶ 실행 가능 배지 + 제목 + 사용 도구 + 실행 수
- 상세
  - 상단: 미리보기 영역 + **[▶ 실행하기]** 버튼 → 샌드박스 모달 (docs/08)
  - 랜딩페이지 유형: 모달 안에 데스크톱 / 태블릿 / 모바일 너비 전환 버튼
  - 소개, 만든 과정(사용한 AI, 프롬프트, 걸린 시간), 소스 링크(GitHub), 다운로드(ZIP, 모션그래픽 소스)
  - 라이선스 표기 (MIT, CC BY, 상업적 이용 불가 등) — **필수 입력**
- 등록 `/make/new`: 등록 방식 선택 — 외부 링크 / ZIP 업로드 / GitHub 저장소
  - 등록 후 상태: `승인 대기` → 운영진 검수 → `공개` 또는 `반려(사유)`
- 모션그래픽: 영상(MP4) 미리보기 + 소스 파일(AE, Lottie JSON 등) 다운로드. Lottie JSON은 페이지에서 바로 재생합니다.

## 5. 바로쓰기 `/tools`
- 목록: `ToolTile` 그리드. 그룹: 생활 / 업무 / 이미지 / 음성
- 각 도구 페이지 공통 구조: **입력칸 하나 → 실행 버튼 하나 → 결과 + 복사·다운로드**
- 상단에 "이 도구는 어떻게 쓰나요?" 접이식 안내 3줄
- 상세 명세와 비용 정책은 `docs/09`를 따릅니다.

## 6. 가이드 `/guide`
상단 탭: **AI 서비스 사용설명서 | 스킬·팁**

### AI 서비스 사용설명서 `/guide/services`
- 기존 **aiguidepage** 프로젝트의 툴 가이드를 이곳으로 옮깁니다 (이전 방식은 ORCHESTRATION Q6).
- 목록: 상황별로 찾기 (예: "글을 써야 할 때", "이미지가 필요할 때", "문서를 요약할 때") + 서비스 이름별 찾기
- 서비스 상세 페이지 구성(고정 템플릿)
  1. 한 줄 소개 / 이런 분께 추천
  2. 무료·유료 요금 요약 + **최종 확인일** (예: "2026.10 기준")
  3. 가입 방법 (스크린샷 단계별)
  4. 처음 써보기: 따라 하기 3단계
  5. 자주 쓰는 활용 예시
  6. 이 서비스로 만든 프롬프트 (프롬프트 갤러리 연결)
  7. 회원 사용 후기 (댓글)
- 요금이나 기능은 자주 바뀌므로 **최종 확인일이 90일을 넘으면** 어드민 대시보드에 "갱신 필요"로 표시합니다.

### 스킬·팁 `/guide/tips`
- ChatGPT, Claude, Gemini 활용법과 GitHub, Hugging Face의 프로젝트·스킬·오픈소스 소개
- 글 템플릿(필수 항목): **무엇인가요? / 어디에 쓰나요? / 어떻게 설치·사용하나요? / 주의할 점 / 원문 링크**
- 난이도 배지: 입문 / 중급 / 고급
- 다운로드 파일(스킬 등)이 있으면 버전과 다운로드 수를 표시합니다.

## 7. 배우기 `/learn`
- 메인: 추천 커리큘럼(가로 스크롤) / 주제별 플레이리스트 / 최근 본 영상 / 진행 중인 스터디
- 커리큘럼 상세 `/learn/courses/[id]`: 강의 목록(회차), 진행률, 다음 강의 이어보기
- 학습 플레이어 `/learn/watch/[videoId]`: 왼쪽 유튜브 플레이어, 오른쪽 탭(요약 / 타임스탬프 / AI 질문 / 메모). 상세는 `docs/09`
- **스터디방** `/learn/study`
  - 스터디 목록: 진행중 / 모집중 / 종료
  - 스터디 상세: 소개, 일정, 참여자, 회차 목록
  - 회차 페이지 `/learn/study/[id]/[n]`: 학습 자료(영상, 가이드 링크) → 과제 설명 → **과제 제출**(프롬프트 또는 만들어보기 작성 화면으로 이동, 회차 정보 자동 연결) → 제출물 모아 보기 → 출석 체크
- 같이보기 `/learn/watch-party/[roomId]`: 3단계 기능 (docs/09)

## 8. 커뮤니티 `/community`
- 게시판: **자유 / Q&A / 공지** 3개만 둡니다. 세부 분류는 태그로 처리합니다.
- 기본 보기는 **게시판 목록형**(`BoardList`): 번호 · 말머리 · 제목 [댓글 수] · 작성자(등급 아이콘) · 날짜 · 조회 · 추천
- 상단 고정: 공지 최대 3개
- 말머리: 일반 / 질문 / 활용팁 / 후기 / 모임 (시안 태그 색상 사용)
- 추천 태그: `#입문`, `#ChatGPT`, `#Claude`, `#이미지생성`, `#바이브코딩`, `#스터디`
- Q&A
  - 답변 채택 기능 (질문자만 가능, 채택하면 답변자에게 포인트 지급)
  - 채택되지 않은 질문이 3일 지나면 운영진 알림
  - "입문" 태그가 붙은 질문은 목록에서 🌱 아이콘으로 표시해 쉽게 답하도록 유도
- 글쓰기: 리치 에디터(굵게, 목록, 이미지, 코드 블록, 링크 미리보기), 임시 저장
- 다른 메뉴 콘텐츠를 링크하면 카드 형태로 미리보기가 나옵니다 (프롬프트, 작품, 가이드).

## 9. 검색 `/search`
- 결과 탭: 전체 / 프롬프트 / 만들어보기 / 가이드 / 커뮤니티 / 뉴스
- 검색어 강조 표시, 최근 검색어(로컬 저장), 인기 검색어(어드민 설정)

## 10. 마이페이지 `/me`
- 탭: 내 글 / 내 댓글 / 저장한 것 / 내 작품(승인 상태 포함) / 스터디 / 알림 / 설정
- 설정: 닉네임, 프로필 이미지, 소개, 언어, 테마, 알림 수신(댓글, 채택, 승인 결과, 행사)
- 등급과 다음 등급까지 남은 조건 표시 (docs/07)

## 11. 공개 프로필 `/u/[nickname]`
- 닉네임, 등급, 가입일, 활동 요약(글, 작품, 채택 답변 수), 공개 작품 목록

## 12. 에러 · 상태 페이지
- 404: "찾으시는 페이지가 없어요" + 홈·검색 버튼
- 권한 없음: "로그인이 필요해요" / "운영진만 볼 수 있어요"
- 점검 중: 어드민 설정에서 켜고 끌 수 있음
