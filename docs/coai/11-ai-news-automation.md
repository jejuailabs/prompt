# 11. AI 뉴스 일일 자동 발행 (설계안 — 미구현)

AI 일정 수집(`src/modules/event-ingest`) 다음 단계. 하루 2~3건, 외부 원문을 **재가공한 우리 글 + 인포그래픽 + AI 운영자 평가**로 올린다. SEO(검색)·AEO(AI 답변 인용) 노출이 목적.

## 1. 글 구조 (기존 `coai-news` 확장)
현재 `NewsInput`(분류·제목·3줄 요약·운영진 해설·"나한테 무슨 의미"·출처·이미지)을 유지하고 필드를 더한다.

| 위치 | 내용 | 비고 |
|---|---|---|
| 맨 위 | 제목, 3줄 요약(`summary`), **AI 운영자 한줄평**(`commentary` 앞부분) | 답을 먼저 주는 구조 = AEO 인용에 유리 |
| 본문 | 재가공 본문(`body`, 600~1,200자), 핵심 수치 인포그래픽(`infographic`) | 원문 문장 복사 금지, 사실만 가져와 새로 서술 |
| 아래 | **운영자 평가**(`review`: 의미·기대·우려·실무 영향·한 줄 결론, 선택 점수) + FAQ 2~3개(`faq`) | FAQ는 FAQPage JSON-LD로도 출력 |
| 맨 끝 | 출처 이름·원문 링크, 발행일/수정일 | 출처 표기 필수 |

AI 평가는 "AI가 쓴 의견"임을 분명히 표기하고, 사실(수치·날짜)은 원문에서 확인된 것만 쓴다(`extract.ts`와 같은 "본문에 없으면 쓰지 않는다" 규칙).

## 2. 파이프라인 (매일 1회, 일정 수집과 같은 크론 패턴)
1. **후보 수집**: AI 기업 공식 블로그/보도 RSS, 국내 AI 매체 RSS(제목·요약·링크만), 정부 정책 보도. 소스는 `sources.ts`처럼 행 추가 방식.
2. **선별**: 최근성·출처 신뢰도·국내 독자 관련성·기존 기사와 중복 여부로 점수화 → 상위 2~3건. 원장(ledger)으로 재처리 방지.
3. **원문 읽기**: robots.txt 허용 페이지만. 막힌 곳은 RSS 요약만 사용.
4. **재가공**: 1건당 한 번의 AI 호출로 `summary/body/review/faq/infographic 데이터(JSON)` 생성. 제목·메타 설명(120자)·슬러그 포함.
5. **인포그래픽**: AI가 낸 수치/타임라인/비교 JSON을 **SVG 템플릿**으로 렌더(서버에서 sharp로 PNG 변환). 이미지 생성 비용 0. 대표 이미지만 필요할 때 `gpt-image`(장당 비용 기록).
6. **게시**: 관리자 승인 없이 발행하되 `status`로 즉시 숨김 가능. 첫 2주는 `draft`로 쌓아 두고 검수 후 자동 발행으로 전환 권장.

## 3. SEO / AEO 필수 조건 — 먼저 해결할 구조 문제
- 지금 뉴스는 SPA 뷰(`view-router`)라 **기사별 고유 URL·서버 렌더 메타데이터가 없으면 검색·AI 크롤러가 개별 기사를 인덱싱하지 못한다.** `/news/[slug]` 서버 렌더 라우트가 선행 조건.
- 페이지당: `<title>`, meta description, canonical, OG 이미지, `NewsArticle` + `FAQPage` JSON-LD, 발행/수정일, 저자(= "COAI AI 운영자" 표기), 관련 기사 내부 링크.
- `sitemap.xml`에 기사 추가, 필요하면 `llms.txt`로 기사 목록 노출. 네이버 서치어드바이저·구글 서치콘솔에 사이트맵 제출(사이트 인증 값은 이미 `NAVER_SITE_VERIFICATION` 있음).

## 4. 저작권·품질 가드
- 원문 문장·이미지 복제 금지(인포그래픽은 수치 사실만 사용), 출처 링크 표기, 같은 원문을 두 번 쓰지 않음.
- 추측/과장 금지 문구를 시스템 프롬프트에 고정, 수치는 원문 대조(숫자가 본문에 없으면 제거).
- 하루 발행 상한·AI 호출 상한·공급자 크레딧 소진 시 중단(일정 수집과 동일).

## 5. 비용 감각 (가정치, 도입 전 공식 가격 확인)
기사 3건/일 × (입력 약 8천 + 출력 약 3천 토큰) → 중급 모델 기준 월 수천~1만 원대. 인포그래픽은 SVG라 0원, 대표 이미지를 AI로 만들면 장당 약 $0.04~0.07 가정(월 약 1.5만~2.5만 원).

## 6. 구현 순서 제안
1. `/news/[slug]` 서버 렌더 + 메타/JSON-LD + 사이트맵 (기존 뉴스에도 즉시 SEO 효과)
2. `NewsInput` 확장(body/review/faq/infographic) + 상세 화면 레이아웃
3. 후보 수집·선별·재가공 크론 (`src/modules/news-ingest`)
4. SVG 인포그래픽 템플릿 3종(수치 비교, 타임라인, 체크리스트)
5. 2주 draft 검수 후 자동 발행 전환
