# 01. 제품 개요 · 브랜드

## 1. 목적

AI 기술과 결과물은 최신이지만, 그것을 나누는 사람들에게는 **익숙한 커뮤니티 인터페이스**를 제공합니다.
보는 데서 그치지 않고 **배우고 → 써보고 → 만들어 보여주는** 흐름을 한곳에서 경험하게 합니다.

## 2. 대상 사용자

| 구분 | 특징 | 설계 시사점 |
|---|---|---|
| 핵심 | 30대 중후반~60대 초반 | 큰 글씨, 높은 대비, 익숙한 게시판·카드 UI |
| 문화적 배경 | PC통신, 다음카페, 싸이월드, 디시 갤러리 세대 | 말머리, 댓글 수, 조회수, 등급제, 자료실 감성 |
| 참여 경로 | 당근 모임, 오프라인 스터디 | 행사·스터디 중심 운영, 모임 회원이 콘텐츠를 채움 |
| 주요 동기 | "이거 어떻게 해요?" (추정) | Q&A, 따라 하기 가이드, 바로 써보는 도구 |

## 3. 핵심 경험 흐름

```
배우기 / 가이드  →  바로쓰기 / 프롬프트  →  만들어보기 / 커뮤니티
   (이해)              (사용)                  (발표·공유)
```

스터디 과제 결과물이 프롬프트 갤러리와 만들어보기에 쌓이면서 콘텐츠가 자연스럽게 채워지는 구조입니다.

## 4. 브랜드: COAI

### 4.1 이름의 의미
- **CO**: **Collaboration(협업) · Color(색·개성) · Communication(소통)** — 2026-10-21 사용자 확정. 넓게는 Co-work, Community, Co-learning, 그리고 "같이"
- **AI**: 인공지능
- 의미: "AI를 같이 배우고, 같이 쓰고, 같이 만든다"
- 태그라인(시안 그대로): **"쉽게 보고, 바로 써보는 AI 커뮤니티"**

### 4.2 로고 컨셉

**심볼: 두 개의 원 + 스파크**
- 겹쳐진 두 원은 C와 O이자 **두 사람(함께)**을 뜻합니다.
- 두 원이 겹치는 교집합 자리에 **4각 스파크(✦)**를 두어 **AI**를 표현합니다. 사람과 사람이 만나는 지점에서 AI가 반짝인다는 의미입니다.
- 시안의 기존 로고(주황색 사람 + 반짝임 형태)와 같은 컬러, 같은 무게감을 유지합니다.

**워드마크**
- `CO` + `AI`를 붙여서 씁니다: **COAI**
- `CO`는 잉크색(`--color-text-strong`), `AI`는 브랜드색(`--color-brand`)
- 굵기: ExtraBold(800), 자간 -2%
- 헤더 배치는 시안과 같습니다: `[심볼] COAI  쉽게 보고, 바로 써보는 AI 커뮤니티`

**초기 SVG 시안 (디자이너 검토 전 개발용 플레이스홀더)**

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 160 40" role="img" aria-label="COAI">
  <!-- 심볼: 두 원 + 스파크 -->
  <g fill="none" stroke="currentColor" stroke-width="3.5" class="coai-mark">
    <circle cx="14" cy="20" r="10" style="stroke:var(--color-brand)"/>
    <circle cx="26" cy="20" r="10" style="stroke:var(--color-brand-soft-strong)"/>
  </g>
  <path d="M20 12 L22 18 L28 20 L22 22 L20 28 L18 22 L12 20 L18 18 Z"
        style="fill:var(--color-brand)"/>
  <!-- 워드마크 -->
  <text x="44" y="29" font-family="Pretendard, sans-serif" font-weight="800" font-size="24" letter-spacing="-0.5">
    <tspan style="fill:var(--color-text-strong)">CO</tspan><tspan style="fill:var(--color-brand)">AI</tspan>
  </text>
</svg>
```

**로고 사용 규칙**
- 최소 크기: 심볼 20px, 워드마크 높이 18px
- 여백: 심볼 높이의 50% 이상
- 다크 모드: `CO`는 흰색 계열로 바뀌고, `AI`와 심볼은 브랜드색을 유지합니다 (토큰으로 자동 처리).
- 파비콘과 앱 아이콘: 심볼만 사용합니다.

> ⚠️ "COAI" 이름과 로고의 **상표 등록·중복 여부는 확인하지 않았습니다.** 정식 오픈 전에 KIPRIS(특허정보검색서비스) 등에서 확인이 필요합니다.

## 5. 메뉴 한눈에 보기 (상세는 02, 04 문서)

| 메뉴 | 한 줄 정의 |
|---|---|
| 홈 | 전체 콘텐츠 요약, 포스터 슬라이드 |
| 뉴스·이벤트 | AI 뉴스 + 세미나·스터디·모임 포스터 갤러리 |
| 프롬프트 | 결과물을 먼저 보고 프롬프트를 복사하는 갤러리 |
| 만들어보기 | 모션그래픽, AI 게임, 바이브코딩 결과물을 샌드박스에서 실행 |
| 바로쓰기 | 사이트 안에서 바로 쓰는 자체 도구 (QR, TTS, 요약 등) |
| 가이드 | AI 서비스 사용설명서 + 스킬·팁·오픈소스 소개 |
| 배우기 | 유튜브 커리큘럼, 학습 플레이어, 스터디방 |
| 커뮤니티 | 자유게시판, Q&A, 공지 (태그와 검색 중심) |

**이름 정리 원칙**: 자체 기능은 **"바로쓰기"**, 외부 AI 서비스(ChatGPT, Claude 등) 소개는 **"가이드"**로 구분합니다. 혼동을 막기 위해 "AI 도구"라는 단어는 메뉴 이름으로 쓰지 않습니다.

## 6. 단계 계획

| 단계 | 범위 |
|---|---|
| 1단계 | 홈, 뉴스·이벤트, 프롬프트, 커뮤니티, 가이드, 바로쓰기(비용 없는 도구), 회원, 어드민 |
| 2단계 | 만들어보기(정적 ZIP), 배우기(커리큘럼·플레이어), 스터디방 |
| 3단계 | 같이보기(실시간), 영상 AI 질문, GitHub 빌드 실행, 유료 API 도구 |

## 7. 성공 지표 (초기)

- 주간 활성 회원 수 (당근 모임 회원 대비 가입 전환율)
- 스터디 회차별 과제 제출률
- 회원이 올린 프롬프트·작품 수 (운영진 글 대비 비율)
- Q&A 답변 채택률, 첫 답변까지 걸린 시간
