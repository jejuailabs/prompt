# 코드볼·벨벳 블랙잭·숨은 고양이·메종 마인

2026-10-11 사용자 프리브리핑 승인 후 구현. 기존 수정은 URL와 게임 ID를 보존하며, 네 게임은 이미지·소리·실행 코드를 포함한 독립 정적 패키지다.

## 실행과 이식

|---|---|---|---|
| 코드볼 | /games/code-ball/index.html | public/games/code-ball | 숫자/문자 후보/A~Z × 3→6 또는 고정 자리; 일일 공통 문제 |

구 URL 두 개는 상대 경로로 새 패키지에 연결하며 query/hash를 보존한다. 각 폴더의 game.manifest.json에는 버전, 파일, 에셋, 실행 조건과 lifecycle 계약이 있다. WebGL·Next.js·로그인·API·런타임 CDN 없이 실행된다. Web Audio 사운드는 코드로 합성한다.

`node scripts/package-puzzle-games.cjs`로 runtime.mjs/base.css를 각 폴더에 고정 복사하고 매니페스트, src/lib/puzzle-games.generated.ts, exports/games/<id>-<version>.zip을 만든다. 기존 3D 패키징 스크립트는 DOM 패키지를 건드리지 않는다. 등록은 LITTLE_WORLDS 레지스트리에 합쳐지며 기존 hidden-paws/minesweeper ID와 URL을 유지한다.

## 게임 규칙

코드볼: 중복 없는 0~9 또는 영문 코드. 숫자 0은 첫 자리에도 가능. 3→4→5→6 후 새 6자리 문제를 계속 생성한다. 고정 3/4/5/6자리도 지원한다. 문자 후보 모드는 A~Z 중 길이×2+2개의 후보를 보여주고 전체 A~Z 모드는 별도 경쟁이다. 모든 추리에서 S는 같은 자리, B는 다른 자리의 같은 기호 개수만 알려준다. 어떤 기호가 맞았는지 표시하지 않는다. 기호를 차례로 누르면 빈칸 자동 배치·판독 후 입력 전체 비우기·명시적 칸 수정·데스크톱 드래그·키보드·이전 조합 불러오기·우클릭/메모 후보 표시, 동일 추리 재제출 억제. 문제당 10회. 해결 점수는 자리 수·시도·연속 해결이 중심이고 작은 시간 보너스가 있다. 연습은 외부 점수를 내지 않는다.

오늘의 도전은 한국시간 날짜와 기호 모드로 같은 3/4/5/6자리 네 문제를 생성한다. 첫 시작을 기기에 저장하며 재시작은 연습이 된다. 서버는 계정·날짜·기호 모드당 첫 완료 제출 하나를 저장한다. 첫 시작 제한은 기기 저장에 의존하므로 새 기기/저장소 초기화까지 서버가 막는 시험형 시스템은 아니다. 기존 게임과 동일한 클라이언트 점수 계약이며 서버가 전체 추리 과정을 재생 검증하는 방식은 포함하지 않는다.

블랙잭: 가상 칩 1,000, 목표 모드 딜러 3,000/목표 3,000, 파산 모드 딜러 1,500. 최대 30핸드, 현재 칩으로 마무리 가능. 6덱 슈, 75장 미만이면 새 핸드 전에 셔플. A 1/11, 내추럴 3:2, 푸시 반환, 딜러 소프트17 스탠드. 히트/스탠드/첫 두 장 더블/스플릿 후 더블/같은 값 스플릿/최대4핸드/스플릿A 각1장/스플릿21은 일반승리/딜러A 보험/딜러 내추럴 확인/늦은 서렌더 절반 반환. 보험은 배당 2:1(원금 포함 3배). 플레이어·딜러 잔고 이동을 하나의 정산으로 처리하며 실패·승리 목표가 한 세션에서 끝난다. 실제 돈·결제 없음.

고양이: 온실 5→7→9→12→15. 이후 서재/주방/달빛정원 15마리를 유지하고 크기를 7.5%까지 점진 축소하며 위치와 종류를 바꾼다. 네 배경마다 18개 후보 위치. 6종 기존 고양이, 장면별 3힌트, 확대 1~3배/캡처 드래그/취소, 찾은 표시·음향. 찾기 점수+완료 보너스, 힌트·실수·시간이 완료 보너스에 반영된다. 첫 장면부터 시작한 세션만 랭킹, 15마리와 새 배경 바로 시작은 연습이다. 이전 5마리 게임 온라인 기록은 별도 이전 기록 메뉴로 조회하며 기존 저장 키를 삭제하지 않는다.

지뢰찾기: 초급9×9/10, 중급16×16/40, 고급30×16/99. 사용자 지정8~30열, 8~24행, 지뢰수 안전 제한. 첫 열린 칸만 안전, 주변3×3 보장이나 무추측 생성으로 고전 규칙을 바꾸지 않는다. 빈 영역 펼치기, 깃발 칸 보호, 물음표 열기, 모든 안전칸 승리(깃발 필수 아님), 승리 자동 깃발, 패배 지뢰·오깃발 표시, 음수 지뢰카운터, 첫 열기부터 타이머, 웃는 얼굴 재시작. 왼쪽 누름·커서 이동·해제/판 밖 취소, 우클릭 깃발→?→빈칸(물음표 설정), 양 버튼 동시 주변 누름·첫 해제 판정, 두 버튼 모든 입력 순서, 가운데, 오른쪽 유지+왼쪽 반복 1.5클릭, Shift+왼쪽. 고전판에 없는 숫자 더블클릭 자동 열기는 기본으로 추가하지 않았다. 실제 독립 mouse down/up으로 양 버튼의 첫 해제를 받는다. 터치 길게/깃발 모드, 판 안쪽 스크롤·전체 보기·확대축소. 일시정지는 판을 가리고 타이머를 멈춘다. 실패·사용자 지정은 랭킹 제외.

## 랭킹과 연동

부모 source/origin/gameId/contractVersion 검증. score/roundId/durationMs/rankingKey를 전송하고 서버 저장 확인 때 pending을 제거한다. 호스트 로그인과 DB는 교체 가능하다.

GamePlay 기존 스키마를 유지한다. 모드별 기록은 `rank-<rankingKey>-<hash>` ID로 저장하며 같은 prefix로 최고점을 조회한다. 기존 기록은 prefix 없는 이전 기록으로 분리된다. 지뢰 시간은 `100000000 - milliseconds`로 순서를 저장하고 UI에서 초로 복원한다. 일반 전 게임 점수판에는 시간 인코딩을 넣지 않아 다른 아케이드 점수를 압도하지 않는다. 게임 카드의 서로 다른 모드 최고값을 하나의 순위로 합치지 않는다.

## 코드볼 1.1.0 입력·그림 개선

[Mastermind Arena](https://mastermindarena.app/)의 추리 기록과 키보드 안내, [Anywhere Play Bulls and Cows](https://www.anywhereplay.com/daily/bulls-and-cows)의 고정 S/B 기록·키패드·일일 공통 문제를 실제 화면에서 확인했다. 장점을 기록·입력·모드 안내에 적용했다. 칸마다 별도 선택하는 불편은 사용자 지시대로 순차 자동 배치로 개선했다. 다른 게임의 이름·그림·코드를 복제하지 않았다.

키패드 DOM은 입력마다 재생성하지 않는다. 3개 누르면 3칸, 6개 누르면 6칸에 입력한다. 유효 판독은 정답/오답 모두 전체 입력을 비운다. 중복·미완성·동일 추리 재제출은 횟수를 소비하지 않는다. 과거 조합 ↺는 복사 후 선택 수정 가능하고, 키보드 Backspace/Delete/Enter와 메모·우클릭을 지원한다. 메모는 후보→제외→해제이며 답을 자동 노출하지 않는다. 슬롯 수정은 선택한 칸을 바꾼 뒤 다음 빈칸으로 이동한다.

고양이 코치·야구장 high 이미지와 청록 전광판·크림 추리 기록·촉감 키패드로 교체했다. 생성 프롬프트는 assets/art-prompts.json. 한글·숫자 Pretendard, 제목 Fredoka/Cinzel의 로컬 서체·라이선스·해시를 패키지에 포함했다. [서체 선정 기록](game-typography.md). 코드볼1.1.0, 나머지 DOM 패키지1.0.1.
