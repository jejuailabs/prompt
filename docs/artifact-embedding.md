# 게임·결과물 퍼가기와 게임 버튼 수정

2026-10-23 로컬 구현. 공개 배포와 운영 데이터 쓰기는 실행하지 않았다.

## 사용

게임 모달 상단과 작품 상세의 `공유 · 퍼가기`에서 공유 링크 또는 HTML iframe 코드를 복사한다. 복사 권한이 없으면 오류를 알리고 내용을 직접 선택해 복사할 수 있다. 게임 공유창을 열어도 같은 iframe과 진행 중인 판을 유지한다.

`/embed/{artifactId}`는 메뉴 없이 작품과 COAI 원본 링크를 표시한다. 공개·게시 작품만 `/api/embed/{artifactId}`의 읽기 전용 경로로 제공한다. 비공개·일부 공개·초안·숨김·보관 상태 및 별도 비공개 랜딩페이지 결과물은 제공하지 않는다. 이 경로는 조회수·플레이·광고·점수 기록을 쓰지 않는다. 내장 게임은 코드 레지스트리만으로 실행하고 DB를 요구하지 않는다.

회원 앱·게임은 기존 실행 엔진의 sandbox를 유지한다. 사이트와 같은 origin에서 실행할 수 있는 예외는 코드 레지스트리에 정확히 일치하는 내장 게임 진입점뿐이다. 임의의 로컬 경로나 다른 도메인에 같은 이름을 붙인 URL은 이 예외에 포함하지 않는다. 내장 모듈에는 embed·parentOrigin을 전달하여 상대 리소스와 저장소, 부모 메시지 검증을 유지한다.

iframe을 허용하지 않는 블로그 편집기나 원본 서버가 외부 임베드를 차단한 작품은 공유 링크를 사용해야 한다. 새 호스팅·유료 API·광고 SDK는 추가하지 않았다.

## 게임 버튼

3D 공통 런타임의 HUD는 z-index 2, 시작·일시정지·결과 안내창은 z-index 4여서 음소거와 일시정지 버튼이 안내창에 가려졌다. 전역 조작 버튼만 HUD의 stacking context 밖으로 옮겨 안내창 위에 표시한다. 게임 그림·점수·물리·오버레이의 나머지 배치는 유지한다.

퍼즐 공통 런타임도 안내창보다 상단 조작부를 높인다. 야구의 sticky 헤더를 포함한 개별 레이아웃이 공통 스타일을 덮어쓰는 경우까지 처리한다. 13개 게임에 패치 버전을 부여하고 기존 파일·에셋 목록을 유지한 ZIP을 `exports/games`에 갱신했다. `node scripts/game-module-kit/archive.cjs <game-id> ...`는 검증된 파일을 변경하지 않고 manifest 목록으로 ZIP을 생성한다. 공통 패키저가 별도 런타임인 번개 냥이의 화면을 덮어쓰지 않도록 대상도 제한했다.

게임 모달의 전체화면은 Tailwind의 개별 `translate` 속성도 초기화한다. 기존 `transform:none`만으로는 중앙 정렬 이동이 남아서 상단 버튼이 화면 밖으로 밀릴 수 있었다.

## 검증

- `controls-qa.cjs`: 13개 게임 × 1100×820 / 390×700 / 844×390의 39개 조합. 실제 클릭으로 시작, 시작 전·플레이·일시정지·재개 상태의 음소거, 일시정지 버튼으로 재개와 브라우저 오류 없음을 확인했다. 별도 로컬 정적 서버의 `/relocated/{game-id}/`에서 실행했다.
- 게임 발견·랭킹·물리·퍼즐·퍼가기·Godot 오디오/종료 수명주기 회귀 테스트 총 47개 통과. ZIP 13개의 386개 파일이 현재 독립 패키지와 바이트 단위로 일치함도 확인했다.
- `embed-qa.cjs`: 별도 origin의 로컬 정적 페이지에 실제 복사한 iframe을 넣어 실행한다. PC·모바일에서 게임/작품 공유창, 클립보드, 게임 iframe 보존, 내장 게임 조작, 이미지, 긴 텍스트, 회원 앱 sandbox를 확인한다. 네트워크를 로컬 또는 명시적으로 모의한 응답으로 제한한다.
- TypeScript noEmit과 변경 대상 ESLint를 검사한다. 브라우저 검증은 Chromium 모바일 에뮬레이션이며 실제 iPhone/Android 검증은 포함하지 않는다.

위 브라우저 검증과 TypeScript/ESLint는 모두 통과했다. 전체화면에서 공유창 열기까지 확인했으며, 임시 공개 HTML과 이 작업에서 시작한 QA 서버는 종료·정리했다.

다시 실행할 때는 로컬 디자인 미리보기 서버(`PLAYLAB_DESIGN_PREVIEW=1`, `COAI_QA_DIST_DIR=tmp/share-qa-next`, 포트 4177)와 `node scripts/game-module-kit/serve.cjs public 4180`을 먼저 실행한다. 이후 `node scripts/game-module-kit/controls-qa.cjs` 및 `node scripts/game-module-kit/embed-qa.cjs`를 사용한다. QA 빌드 폴더를 분리하여 기존 개발 서버와 충돌하지 않게 했다.
