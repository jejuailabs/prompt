# 게임 모달과 선택형 광고 연결

PC와 모바일의 game-play는 게임룸 위 모달로 실행한다. 모바일은 동적 화면 높이와 안전 영역에 맞추며 부모 페이지 스크롤을 잠근다. 게임·조작 버튼은 iframe 안에 두고 랭킹·설명·공유·관리 도구는 별도 정보 패널로 이동했다. 정보 패널을 열면 독립 게임을 일시정지하며 iframe을 다시 만들지 않는다. 짧은 화면에서는 광고 영역을 접어 플레이 공간을 우선한다. 기존 2D Little Worlds 임베드는 원래 캔버스 비율을 유지하며 전체 카드와 모든 조작을 화면에 맞춘다.

## 광고 자리

GameAdSpace는 상·하단의 표시용 예약 영역이다. 광고임을 명확히 표시하며 게임 버튼과 다른 영역에 둔다. 현재 광고 SDK·게시자 ID·광고 단위는 연결하지 않았고 광고 요청·클릭·노출 집계도 발생하지 않는다. 표시용 영역은 클릭할 수 없다. 기존의 2초 경과만으로 광고 노출을 집계하던 타이머는 제거했다.

일반 AdSense 콘텐츠 광고의 실제 연결은 [게임 페이지 배치 안내](https://support.google.com/adsense/answer/2768340)와 [광고 배치 정책](https://support.google.com/adsense/answer/1346295)을 따르는 공급자 어댑터에서 처리한다. Google은 게임 가장자리에서 150px 이상 이격을 권장하며 조작 버튼과 혼동되는 배치를 금지한다. 현재의 작은 예약 영역을 검토 없이 실제 배너로 치환해서는 안 된다. 모바일에서 이격과 플레이 공간을 동시에 확보하기 어려우면 선택형 전면 광고를 사용한다.

## 광고 보고 이어하기

네온 슬로프 1.3.0은 첫 생명 소진에 한 판당 1회 선택형 이어하기를 지원할 준비가 되어 있다. 공급자가 사용할 광고가 있다고 알린 경우에만 광고 보고 이어서 / 이 기록으로 마무리 선택을 제공한다. 공급자가 없으면 기존처럼 일반 결과·재시작을 사용한다. 광고 완료 시 생명 1개와 안전 위치를 복구하며 같은 라운드 ID·최고 도달 거리·모은 글자를 유지한다. 취소·실패·재고 없음·오래된 응답·중복 응답은 보상을 주지 않는다. 이어하기 선택 단계에서는 최종 점수를 제출하지 않고 최종 마무리 때 한 번만 저장한다.

게임은 광고 SDK를 직접 요구하지 않는다. continuation.mjs에 선택형 계약을 두고 호스트의 useGameAds와 RewardedAdAdapter가 SDK를 교체 가능하게 연결한다. 광고 준비 중 게임 진행과 소리는 멈춘다. 호스트는 같은 iframe·origin·게임 ID를 검증하고 라운드와 요청 ID를 대조한다. 화면 종료 시 요청을 취소하고 90초 응답 지연 시 실패로 복구한다. 기다렸다는 이유만으로 보상하지 않는다.

공급자 구현은 window.playlabRewardedAds에 isAvailable / show를 제공하고 playlab-game-ads-ready 이벤트를 보낸다. show는 rewarded / dismissed / unavailable / failed 중 하나를 반환한다. 실제로 완료된 시청에서만 rewarded를 반환한다.

createAdBreakRewardedAdapter는 Google H5의 [adBreak 콜백 계약](https://developers.google.com/ad-placement/apis/adbreak)에 맞춰 adViewed 뒤 완료 처리에만 보상을 연결한다. adDismissed나 광고 없는 adBreakDone을 성공으로 취급하지 않는다. 게시자 설정·승인·SDK 로딩은 연결 공급자의 책임이며 현재 연결된 실제 네트워크는 없다. Google H5 SDK를 선택하면 [게임 문서 구조 조건](https://developers.google.com/ad-placement/docs/html5-game-structure)을 충족하는 문서에서 로딩하고 iframe 브리지로 어댑터에 연결해야 한다.

다른 게임은 해당 게임에 맞는 복귀 위치·남은 기회·최종 점수 시점을 정의한 뒤 이 계약에 참여한다. 현재는 네온 슬로프만 보상 기능을 선언한다. ZIP을 다른 프로젝트에 옮겨도 광고 없이 그대로 플레이되며 같은 어댑터 계약을 붙이면 이어하기를 제공할 수 있다.

## 검증

게임·광고 계약·콜백·기존 물리와 목록·랭킹을 포함한 회귀 58개, 새 React 파일 대상 린트가 통과했다. game-modal.cjs에서 PC 모달·전체화면 진입/복귀·닫기와 스크롤 복원, 모바일 390×780·844×390·320×568 화면 맞춤·부모/iframe 무스크롤, 네온 슬로프의 모의 SDK 취소/완료와 같은 판 1회 복귀를 확인했다. 프리즘 타워·포켓 크로싱·과일·젤리·루나 핀볼·스페이스 슈터의 작은 화면과 하단 버튼 잘림도 확인했다. 실제 휴대폰 검사가 아닌 Chromium 에뮬레이션이며 실제 광고 시청·송출 검증은 아니다.

독립 1.3.0 ZIP을 다른 프로젝트 경로에 배치한 검사에서 세 캐릭터·LIFE·속도·500m와 점프/착지 4회 및 외부 요청 없는 실행을 확인했다. 닫기 시 finalize 명령과 요청 취소·기록 마무리도 단위 계약에서 검사했다.

최종 TypeScript·프로덕션 빌드가 통과했고 최신 로컬 서버에서 PC 모달/전체화면·모바일 세로/가로 무스크롤·모의 SDK 취소/완료를 다시 확인했다. SDK·배너 실제 송출은 미연결 상태다.
