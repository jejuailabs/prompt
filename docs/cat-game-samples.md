기존 두툼한 식빵 몸통을 유지한다. 자체 3D 모델과 실제 렌더링한 PNG 7장이 각 패키지에 포함된다. 색만 바꾸지 않고 귀·눈·얼굴 무늬·털·꼬리로 구별한다. 등장 순서는 게임의 시각적 연출이며 실제 품종 가치의 순위가 아니다. 이미지 모음: public/games/prism-stack/breeds.html. 원본 코드: scripts/cat-module-kit/cats.mjs 및 breeds.mjs.

## 1.3.1 혼합 등장

프리즘은 처음 네 번의 배치에 기본 고양이 네 색상을 각각 한 번씩 등장시킨다. 5·10·15·20·25·30층에서는 새 품종을 처음 한 번 확정 등장시키며, 그 이후에는 기존 기본 네 색상과 해금된 모든 품종을 섞어 뽑는다. 해금은 기존 친구를 교체하지 않는다. 현재 등장 목록을 한 번씩 섞어 소비하고 같은 외형이 연속으로 나오지 않게 조정한다. 모든 품종을 해금하면 네 기본 색상과 여섯 추가 품종의 총 열 외형이 함께 나온다. 잘린 몸통과 떨어지는 조각도 원래 고양이의 색·품종을 유지한다.

## 속도

프리즘 기본 속도는 2 + min(2.5, 층수 × 0.07). 샘플의 기본 템포는 1 + min(0.8, 단계 × 0.025). 사용자 배율은 1–2배이며 현재 단계의 기본값에 곱한다. 저장값·UI 입력 모두 1 미만을 차단한다. 새 판에서는 단계가 초기화되고 배율은 유지한다. 포장 퍼즐에서는 이 배율로 시간 진행이 빨라진다. 배율은 게임별로 저장한다.

각 샘플은 플레이 시작·한 판 점수·완료/실패·기록으로 마무리·일시정지·재개·재시작·소리·기기 최고 기록을 제공한다. 친구 선택은 외형만 바꾸며 능력은 같다. 마우스·터치·키보드를 지원한다. 포장은 번호 선택·방향키·R·Enter도 지원하며 항상 풀 수 있는 직사각형 분할로 판을 만든다.

## 이식

각 public/games/<id>/ 폴더 또는 exports/games/<id>-1.1.0.zip을 통째로 정적 서버에 배치한다. 엔진, 라이선스, 모델 코드, PNG, 스타일, 썸네일, manifest, README, SOURCES를 포함한다. 호스트 API·CDN·로그인 없이 실행하며 리소스는 상대 경로다. 호스트의 점수 연동은 기존 계약 v1을 유지한다. 재패키징: node scripts/package-cat-games.cjs. 문서화한 80개 기획은 [cat-game-ideas.md](cat-game-ideas.md)에 보존한다.

## 검증

- 캐릭터·속도·점프/뒤집기·80개 시드의 포장 해결 가능성·기존 3D 물리·게임 목록·랭킹 회귀 39개 통과. 별도 패키지 파일 목록 검사도 추가했다.
- scripts/cat-module-kit/qa.cjs: 실제 마우스와 네이티브 모바일 터치로 충전·놓기·착지, 포장 드래그·회전·배치, 품종 선택, 1배 하한, 일시정지·재시작·기록 종료·재도전·자원 해제 확인.
- 프리즘 30층 실제 배치로 메인쿤 등장과 현재 층수 기본 속도 하한 확인.
- 최종 ZIP만 tmp/cat-samples-transfer/mini-games/에 풀어 원본 프로젝트 없이 같은 검증 통과. 외부 요청·JavaScript 오류·QA 점수 POST 없음.
- TypeScript 전체 검사 통과. 모바일 검증은 Chromium 모의 환경이며 실기기 GPU 측정을 뜻하지 않는다.
