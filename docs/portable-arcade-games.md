# 독립 3D 아케이드 게임

2026-10-11 구현. Tower Rush, Slope, Crossy Road의 핵심 플레이 구조를 참고해 프리즘 타워, 네온 슬로프, 포켓 크로싱을 제작했다. 그래픽과 소리는 프로젝트에서 만든 3D 코드·합성 효과음이며, 원본의 그림이나 코드를 사용하지 않았다.

## 게임

- **프리즘 타워**: X/Z 교대 이동, 가로·깊이의 실제 겹침 절단, 잘린 조각의 낙하, 정중앙 연속 기록, 층수·점수, 높이를 따라가는 카메라. 납작한 식빵 고양이, 여섯 가지 파스텔 털색, 둥근 윤곽, 귀·눈·발·꼬리와 부드러운 반사·그림자로 표현한다.
- **네온 슬로프**: 실제 경사면, 자동 전진·점진적 가속, 연속 좌우 조종, 발판 틈에서의 공중 이동과 착지, 낙사, 귀여운 버섯·마시멜로 충돌. 몸 전체가 구르는 햄스터, 120Hz 물리와 네온 캔디 길을 사용한다. 180m에서 스테이지 2로 이어지며 수동 점프·긴 틈·좌우 경사를 제공한다.
- **포켓 크로싱**: 네 방향 한 칸 이동, 이동 중 차량 충돌, 떠가는 통나무 위 탑승·동반 이동, 강 추락, 기차 경고등·경고음과 고속 충돌, 장시간 대기 시 독수리, 코인과 최대 전진 거리 점수. 캐릭터·차량·자연물을 입체 복셀 그래픽으로 구성한다. 이미 지나간 칸을 오가도 거리 점수가 늘지 않는다.

모든 게임은 모바일 터치·키보드, 일시정지·재개·재시작, 소리 설정, 기기 최고 기록을 지원한다. 라운드마다 상태를 초기화하고 영구 성장에 의존하지 않는다.

## 패키지와 등록

각 `public/games/<game-id>/`는 `index.html`, `game.mjs`, `rules.mjs`, `runtime.mjs`, `scene.mjs`, `game.css`, `cover.png`, `game.manifest.json`, README·출처와 로컬 `vendor/`를 포함한다. Three.js 0.172.0 두 엔진 청크와 MIT 라이선스도 함께 이동한다. 타워의 RoundedBoxGeometry 역시 로컬에 포함한다. 외부 CDN·폰트·원본 서버·Next.js에 의존하지 않는다.

`node scripts/package-games.cjs`는 게임 매니페스트를 읽어 공통 런타임을 패키지에 복사하고, `src/lib/portable-games.generated.ts`와 `exports/games/<game-id>-<version>.zip`을 생성한다. 엔진 버전을 검사해 서로 다른 버전이 섞이지 않도록 한다. 폴더 전체 또는 ZIP 전체를 다른 정적 웹 프로젝트의 임의 하위 경로로 옮겨 실행한다.

기존 게임 목록과 랭킹의 내장 ID는 `builtin-prism-stack`, `builtin-neon-slope`, `builtin-pocket-crossing`이다. 기존 게임 ID·URL·기록은 유지한다. 게임룸과 홈페이지의 목록은 기존 레지스트리를 통해 노출한다.

## 호스트 연동

부모 origin은 iframe URL의 `parentOrigin` 설정으로 받는다. 원본 프로젝트의 API 주소를 게임 안에 넣지 않는다. 호스트가 `game-score` 이벤트를 받아 로그인·랭킹을 처리하고 `game-score-saved`로 확인한다. 계약 버전, 게임 ID, 라운드 ID와 점수·플레이 시간을 전달하며 부모 origin·메시지 출처를 검증한다. 시작·일시정지·재개·재시작·리사이즈·종료 명령을 지원하고 종료 시 프레임·입력·오디오·GPU 리소스를 정리한다.

직접 실행의 최고 점수와 보관 점수는 `portable-game:1:<id>:...`에 저장한다. `preview=1`과 `qa=1`은 온라인 점수 이벤트를 보내지 않는다. `qa=1`에만 제공하는 `gameModule.advance(seconds, draw)`는 실제 프레임 로직을 고정 간격으로 진행하는 검증 도구이며 운영 점수 제출에 사용하지 않는다.

## 확인한 검증

- 핵심 규칙 검사: 두 축 절단의 면적 보존, 작은 발판의 정중앙 판정, 연속 경사 연결, 틈 이륙·착지, 최대 속도 장애물 충돌, 낙사, 기차의 프레임 사이 충돌, 통나무 탑승 범위, 최대 전진 거리·코인 점수.
- Chromium: 두 방향 연속 정중앙 8층, 슬로프 키보드 조종·가속, 도로와 두 줄 강 통과, 세 게임의 실패·일시정지·재시작·종료, 데스크톱·390px 모바일 화면. 실제 플레이 화면을 썸네일로 캡처했다.
- `/relocated/<id>/` 실행에서 원본 경로·API·외부 리소스 요청과 JavaScript 오류가 없음을 확인했다.
- ZIP의 파일 목록·에셋·엔진 청크·썸네일 누락을 검사했다. ZIP만 별도 정적 프로젝트의 `/mini-games/<id>/`에 풀어 세 게임의 실제 모바일 터치를 확인했다. 원본 서버·API·외부 리소스 요청이 없었다. 다른 origin의 부모 명령·게임 ID 검증·점수 이벤트·저장 확인 및 잘못된 origin 거부도 통과했다. `scripts/game-module-kit/transfer.cjs`에 검증을 기록했다.
- 실제 프로덕션 게임룸의 세 카드·iframe·랭킹 패널 확인. 실제 X/Z 양쪽 절단과 조각 낙하, 슬로프 420m 자동 조종에서 틈 착지 3회·14개 트랙의 메모리 범위 확인. 운영 QA 랭킹 POST가 없었다. 전체 TypeScript·대상 ESLint·프로덕션 빌드 통과.

브라우저의 모바일 에뮬레이션은 실제 휴대폰 GPU 성능 측정과 다르다. 운영 계정으로 가짜 랭킹 기록을 게시하지 않으며, 랭킹 저장 경로의 서버 회귀는 모의 데이터로 검사한다.

## 프리즘 타워 입력 반응 개선 (2026-10-11)

하단 버튼이 `click`에서만 놓기를 처리해, 누르고 있는 동안에는 블록이 움직이고 손을 뗀 뒤 판정하는 지연을 확인했다. 버튼과 캔버스 모두 기본 포인터의 `pointerdown`에서 현재 보이는 위치로 즉시 판정한다. 물리 클릭의 후속 `click`은 중복 처리하지 않으며 접근성·프로그램 클릭은 유지한다. 버튼에 초점이 있을 때도 Space·Enter를 누르는 순간 처리하고 키 반복과 놓는 동작으로 다음 층이 놓이지 않게 한다.

층마다 200ms 동안 움직임과 입력을 막던 대기를 제거했다. 정중앙 적중은 기존 3D 블록을 위치·색상만 바꿔 재사용하며, 둥근 모서리·유리 재질·반사·그림자·절단 조각과 기존 점수 규칙은 유지한다. 화면은 기존 애니메이션 프레임에서 그리며 추가 강제 렌더링이나 화질 축소를 적용하지 않는다.

`scripts/game-module-kit/prism-input.cjs`는 제어된 프레임에서 실제 마우스·키보드·모바일 터치 입력을 검증한다. 누르는 즉시 1층 증가, 길게 누른 뒤 놓기·반복 키·두 번째 손가락의 중복 방지, 취소 후 다음 터치, 200ms 이내 입력, 두 축 절단과 정중앙 8회 연속을 확인했다. 데스크톱·390px 화면을 캡처했고, 최신 ZIP만 `/mini-games/prism-stack/`에 옮긴 별도 서버에서도 같은 검사를 통과했다. 실제 프로덕션 게임룸 iframe에서도 누름 즉시 배치·놓기 중복 방지·일시정지를 확인했고 QA 랭킹 POST는 없었다. 규칙·목록·랭킹 회귀 20개가 통과했다. 브라우저 핸들러 시간은 화면 표시 지연이나 실제 휴대폰 GPU 성능과 구분한다.

```sh
node scripts/game-module-kit/prism-input.cjs
# PRISM_TEST_URL로 이식한 게임의 QA 주소를 지정해 같은 검사를 실행할 수 있다.
```

## 네온 슬로프 1.1.0: 햄스터와 스테이지 2

`art.mjs`에 동글동글한 햄스터·버섯·마시멜로·캔디 나무를 로컬 3D 코드로 포함했다. 귀·얼굴·발까지 몸과 함께 실제 이동 거리에 따라 회전하며, 이동 방향과 경사면 법선으로 구름 축을 계산한다. 플레이 중 캐릭터와 버튼이 겹치지 않도록 카메라를 조정했고 점프 시 카메라는 트랙을 따라가 길이 보이게 한다.

한 판에서 180m(월드 z=184)에 도달하면 스테이지 2를 자동으로 연다. 스페이스·위 방향키·W·터치 점프 버튼으로 누르는 순간 뛰고, 공중 중복 점프와 키 반복은 허용하지 않는다. 터치 좌우 조종과 다른 손가락의 점프를 동시에 지원한다. 긴 틈 앞 노란 화살표가 점프를 안내한다. 한 판 거리 점수와 기존 랭킹 ID·기기 기록·호스트 계약은 유지한다. 새 판에서는 스테이지 1부터 시작한다.

`course.mjs`의 스테이지 2는 좌우 경사를 양방향으로 바꾸며, 바닥 높이·미끄러짐·착지·렌더링에 같은 경사 값을 사용한다. 연결부의 높이와 기울기를 연속으로 유지한다. 둥근 장애물은 구와 타원체의 거리를 계산해 빈 줄기 주변에서 보이지 않는 상자에 부딪히지 않도록 한다. 점프로 마시멜로를 넘을 수 있다.

6개 신규 물리·100개 시드 코스 검사와 기존 회귀를 포함해 26개 검사가 통과했다. `slope-cute.cjs`에서 실제 500m 질주, 스테이지 전환, 점프 4회·착지 4회, 유지 트랙 10개, 버튼 초점·반복 키, 모바일 동시 조종·점프, 390px·가로 화면, 일시정지·재시작·낙사·GPU 정리를 확인했다. ZIP만 `/mini-games/neon-slope/`에 배치한 별도 프로젝트에서도 같은 검사가 통과했다. 실제 폰 GPU 성능 검사는 에뮬레이션에 포함되지 않는다.

최신 ZIP은 `exports/games/neon-slope-1.1.0.zip`이다. 매니페스트의 버전과 추가 스타일 목록으로 패키지와 레지스트리를 생성하며 `art.mjs`, `course.mjs`, `slope.css`도 함께 이동한다. 썸네일은 새 스테이지 2의 실제 플레이 캡처다.

현재 게임룸의 실제 iframe에서도 새 스타일·햄스터·키보드 조종·구름 회전·일시정지를 확인했고 테스트 점수 POST는 없었다. 전체 TypeScript 검사도 통과했다.

최종 `npm run build`가 통과했으며 새 레지스트리와 정적 자산으로 로컬 앱 서버를 재시작했다.

## 포켓 크로싱 1.0.1: 재시작 캐릭터 높이 복구

익사 때 낮아진 캐릭터의 Y 좌표를 재시작에서 초기화하지 않아 시작 잔디에서도 몸이 파묻히는 문제를 실제 입력으로 재현했다. 수정 전 재시작 직후 Y=-1.1이 유지됐으며, 수정 후에는 다음 프레임을 기다리지 않고 위치 (0,0,0)·기본 크기·방향·날개·그림자·카메라를 초기화한다. 초기 차량·통나무 배치도 즉시 반영한다. 통나무 위의 서 있는 높이를 상판 높이에 맞추고, 올라가거나 내려갈 때 점프 높이를 자연스럽게 잇는다. 기존 게임 ID·점수·최고 기록·연동 계약은 유지한다.

`scripts/game-module-kit/crossing-restart.cjs`에서 익사·차 충돌·독수리 납치·점프 중 일시정지 뒤 실제 다시 시작 버튼, 모바일 터치 재시작, 통나무 착지·동반 이동을 확인했다. 초기화 직후 상태와 실제 화면을 검사했다. 기존 물리 회귀 17개 통과. 최종 `pocket-crossing-1.0.1.zip`만 다른 프로젝트의 `/mini-games/pocket-crossing/`에 배치한 검사도 통과했으며 외부 요청·JavaScript 오류·테스트 점수 제출은 없었다.

## 프리즘 타워 1.1.0: 식빵 고양이 쌓기

밋밋한 블록을 납작한 식빵 고양이로 바꿨다. `cats.mjs`의 자체 3D 코드로 둥근 몸통·귀·얼굴·발·말린 꼬리·무늬를 생성하며 여섯 가지 털색을 쓴다. 움직이는 고양이는 눈을 깜빡이고 귀를 살짝 움직인다. 내려앉으면 귀를 접어 다음 층과 겹치지 않게 하고, 정중앙이면 눈을 가늘게 뜨며 살짝 눌리는 반응과 골골골 콤보를 보여 준다. 받침대 위의 시작 고양이 높이도 맞춰 얼굴·발을 가리지 않는다.

X/Z 두 방향 이동·겹침 절단·발판 축소·조각 낙하·정중앙 판정·점수·누름 즉시 입력은 유지한다. 줄어든 폭과 깊이에 따라 캐릭터도 함께 작아지며 떨어진 조각에는 새 얼굴을 만들지 않는다. 정중앙 적중은 기존 모델을 그대로 쓴다. 한 번 만든 기본 형상과 털색별 장식을 복제하고 GPU 배율로 폭·깊이를 맞춰, 배치 때 정점을 다시 생성·변환하지 않도록 한다. 모바일 카메라는 얼굴과 귀가 화면 밖으로 잘리는 것을 줄였다.

세 가지 새 모델 검사(좁은 발판의 실제 몸통 크기·유한 정점, 정중앙 표정과 모델 유지, 독립 캐시 복제·얼굴 없는 조각)와 기존 게임·물리·목록·랭킹을 포함해 29개 검사가 통과했다. `prism-cats.cjs`에서 실제 두 방향 절단, 여섯 털색·정중앙 반응, 모바일 화면·일시정지·실패·재시작·자원 정리를 확인했다. `prism-input.cjs`에서 실제 마우스·키보드·터치 누름 즉시 배치, 길게 누르고 놓기·키 반복·두 번째 손가락 중복 방지와 취소를 확인했다. 브라우저 핸들러 측정은 실제 기기의 화면 표시 지연과 구분한다.

최신 ZIP은 `exports/games/prism-stack-1.1.0.zip`이며 고양이 소스·실제 썸네일·엔진을 함께 포함한다. 기존 게임 ID·URL·기기 기록·호스트 계약을 유지한다.

최종 고양이 ZIP만 다른 프로젝트의 `/mini-games/prism-stack/`에 배치해 그래픽·두 축 절단·실제 터치·즉시 입력·리소스 경로 검사를 통과했다. 전체 TypeScript·프로덕션 빌드와 실제 게임룸 iframe의 고양이·누름 즉시 배치·손 떼기 중복 방지·일시정지도 통과했으며 테스트 점수 POST는 없었다. 스페이스로 시작하는 입력이 첫 배치까지 연달아 실행되지 않도록 시작 이벤트를 구분했다.

## 네온 슬로프 1.2.0: 세 친구·LIFE·속도 아이템

시작·결과 화면에서 햄스터, 보라색 고양이, 늘어진 귀의 강아지를 선택한다. 선택은 기기에 저장하지만 세 친구의 충돌 반경·이동·점프 능력은 같다. 귀·얼굴·꼬리까지 몸과 함께 구르며 기본 이동은 16→9m/s, 몸의 회전량은 이동 거리 대비 기존의 30%로 완만하게 조정했다. 기본 속도는 초당 0.04m/s씩 최대 15m/s까지 올라간다. 이동 방향과 실제 경사면으로 회전 축을 구하는 방식은 유지한다.

매 판 생명 1개로 시작한다. 코스의 서로 다른 L·I·F·E 네 글자를 순서와 관계없이 수집하면 생명이 하나 늘고 글자는 비워 다음 세트를 모을 수 있다. 중복 글자는 추가 생명을 주지 않는다. 충돌·추락 때 생명 하나를 쓰며, 남은 생명이 있으면 직전 안전한 트랙 위치에서 원래 높이·크기·방향으로 복귀한다. 2.5초 동안 장애물 충돌을 보호하며 최고 도달 거리 점수와 이미 모은 글자는 유지한다. 떨어진 틈을 무료로 건너뛰거나 재수집한 같은 아이템으로 점수를 올리는 방식은 쓰지 않는다. 새 판에서는 생명·글자·거리·효과를 초기화한다.

코스의 주황 ↑는 6초간 속도 1.25배, 민트 ↓는 6초간 0.72배다. 최저 속도는 6.5m/s이며 효과를 겹쳐 무한 가속하지 않고 마지막 아이템으로 교체한다. 일시정지하면 효과 시간과 복귀 보호 시간도 멈춘다. HUD에서 생명 수, 모은 글자, 효과와 남은 초를 볼 수 있다. LIFE 글자는 진행 카메라에서 거꾸로 보이지 않게 방향을 맞췄다.

느린 속도에 맞춰 스테이지 1의 점프 불가능한 틈은 연결했고, 스테이지 2의 필수 점프 틈은 4.4~5.2m로 조정했다. 180m 스테이지 전환, 실제 양방향 경사와 미끄러짐, 즉시 점프·공중 중복 방지·모바일 동시 입력은 유지한다. 속도 다운 최저값과 업 최대값에서 가장 긴 틈의 점프 착지와 점프 없는 추락을 검사한다.

수집·생명·효과·복귀 위치는 로컬 items.mjs에 격리했으며 세 캐릭터와 아이템 도형은 art.mjs에 포함한다. 그래픽과 엔진·실제 썸네일까지 담은 최신 패키지는 exports/games/neon-slope-1.2.0.zip이다. 게임 ID·기기 최고 기록·기존 호스트 계약은 유지한다.

검증: 규칙·물리·100개 시드·기존 게임 모델·목록·랭킹 회귀 총 34개 통과. slope-items.cjs에서 세 캐릭터의 실제 선택·몸 회전, L I F E 실제 수집으로 생명 추가, 추락·장애물 충돌 후 원래 크기와 보호 시간으로 복귀, 스피드 업·다운 실제 획득, 효과의 일시정지·재시작 초기화, 모바일 터치와 가로 화면·자원 정리를 확인했다. slope-cute.cjs에서는 느린 속도로 실제 500m, 스테이지 전환과 점프·착지 4회, 모바일 조종·점프 동시 입력을 확인했다.

최종 1.2.0 ZIP만 별도 프로젝트의 /mini-games/neon-slope/에 배치해 slope-items.cjs와 slope-cute.cjs의 같은 검사를 통과했다. 외부 자산·원본 프로젝트 요청과 JavaScript 오류가 없었으며 모바일 검사는 Chromium 에뮬레이션이다. 전체 TypeScript·프로덕션 빌드 통과 후 로컬 앱 서버를 재시작했고, 실제 게임룸 iframe에서도 세 캐릭터 선택·고양이·낮춘 속도·LIFE HUD·키보드 조종·몸 회전·일시정지를 확인했다. 테스트 랭킹 POST는 없었다.

## 네온 슬로프 1.3.0: 선택형 광고 이어하기 계약

광고 없이 기본 규칙과 LIFE·속도·세 캐릭터·점프는 그대로 동작한다. 선택형 호스트 어댑터가 있을 때만 마지막 생명 소진에서 광고 보고 1회 이어하기를 제안하며, 같은 판·거리·글자를 유지하고 생명 1개와 안전 위치를 복구한다. 모으기로 받은 생명과 별도로 광고 복귀는 한 판 1회다. 최종 마무리 전에는 랭킹 점수를 제출하지 않으며 모달 닫기에서는 먼저 finalize 명령으로 기록을 확정한다. SDK 완료만 보상하고 취소·재고 없음·실패·중복·다른 요청에는 보상하지 않는다. 게임에는 continuation.mjs와 선택형 계약 선언을 함께 포함한다. 실제 광고 SDK는 현재 미연결이다. 상세 호스트 구조와 검증은 [게임 모달과 선택형 광고 연결](game-modal-and-ads.md)을 참조한다. 최신 ZIP은 exports/games/neon-slope-1.3.0.zip이다.
