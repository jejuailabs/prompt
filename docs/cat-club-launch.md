# 2026-10-12 고양이 클럽 출시와 게임 조작 개선

prompt 프로젝트에 추가한 정식 게임은 냥이 합치기(cat-merge), 냥이 시소(cat-seesaw), 냥이 슬링샷(cat-sling) 세 종이다. 기존 프리즘과 샘플 세 종의 URL과 기록은 유지한다.

## 세 게임

- 합치기: 조준 중에는 떨어지지 않고 손을 떼면 한 번 낙하한다. 같은 품종이 만나면 다음 품종으로 합체한다. 네 기본 털색은 같은 기본 품종이다. 고정 120Hz 중력·반발·질량 비례 충돌과 연쇄 점수, 상단 위험 시간, 현재 점수 마무리를 제공한다.
- 시소: 좌우로 움직이는 냥이를 타이밍에 맞춰 올린다. 놓은 위치·쌓인 높이·기울기·미끄러짐이 균형에 영향을 준다. 한계 기울기를 넘으면 냥이들이 환호하면서 함께 다이빙하고 착지 뒤 결과를 보여준다.
- 슬링샷: 화면을 당겨 각도와 힘을 정하고 손을 떼면 발사한다. 실제 궤적 안내·벽 반사·상위 단계 범퍼·정중앙 점수, 세 둥지 완성 보너스와 하트 세 개를 제공한다.

캐릭터는 Three.js의 실제 입체 모델이며 둥근 등·두툼한 몸·발·귀·얼굴·꼬리·품종별 털 장식을 유지한다. 작은 모델의 눈과 입이 세로로 늘어나지 않게 얼굴 비율을 따로 조정했다. 비행·합체·균형·착지·다이빙에 표정과 몸동작을 연결한다. 카메라는 앞면과 윗면을 함께 보여준다. 기본 템포는 단계에 따라 올라가고 사용자 배율은 1–2배만 허용한다.

모든 게임은 한 판 상태를 새 판에서 초기화한다. 게임별 최고 기록, 종료·재도전·일시정지·재개·키보드·마우스·터치와 포인터 취소·창 전환 입력 취소를 지원한다.

## 기존 게임

- 블랙잭 1.1.0: 플레이어/딜러/플레이어/딜러 순으로 한 장씩 나눈다. HIT·더블·스플릿 추가 카드도 순차 진행한다. 딜러는 숨긴 패를 공개한 뒤 한 장씩 뽑는다. 애니메이션 진행은 게임 시간으로 관리해 일시정지 시 멈춘다. 매 핸드의 승패·합계·칩 증감을 표시한다. 목표 달성·칩 소진·30핸드 완료 시 마지막 핸드 결과를 먼저 유지하고 결과 보기 버튼으로 경기 종료 화면을 연다.
- 지뢰찾기 1.1.0: 기본 셀 32–46px, 자동 보기에서도 최소 26px을 유지한다. 긴 판은 아래로 스크롤하고 넓은 판은 좌우로 이동한다. 터치 깃발·길게 누르기, 좌우 동시·가운데·Shift·1.5클릭과 시간 기록을 유지한다.
- 코드볼 1.2.0: PC에서는 입력기를 별도 오른쪽 영역, 모바일에서는 하단 고정 영역에 둔다. 기록은 높이 제한 없이 누적한다. 입력 순서·자동 비우기·불러오기·중복 방지·후보 메모·일일 모드는 유지한다. 320px 화면과 844×390 가로 화면의 26문자 입력도 확인한다.
- 기존 고양이 샘플 1.1.0: 몸통을 두껍게 하고 점프 캐릭터를 크게 배치한다. 포장 캐릭터의 높이 압축을 제거하고 앞면이 보이는 카메라로 바꾼다. 눈·입 비율을 교정하고 성공/실패/배치/완료에 표정을 연결한다. 포장 두 번째 판부터 초기 회전 변주를 추가한다.
- 게임룸: 위 세 클래식 게임에 읽기 레이아웃을 적용해 네이티브 세로 스크롤을 허용하고 상단 광고 자리의 높이를 플레이에 돌려준다.

## 검증

신규 물리 규칙의 합체·유한 값·시소 기울기·다이빙 완료·슬링샷 전 둥지 성공/세 번 실패를 테스트한다. scripts/cat-playground-kit/qa.cjs에서 실제 데스크톱·네이티브 모바일 터치로 점수, 조준 취소, 일시정지, 재시작, 종료, 1배 하한, 자원 해제와 외부/누락 요청 없음을 확인한다. 기존 samples QA와 지뢰·블랙잭·야구 입력 회귀도 실행한다. tmp/cat-club-qa에 실제 화면을 보존하고 게임 썸네일로 사용한다. Chromium 모바일 모의 환경의 검증이며 iPhone 실기기 검증을 뜻하지 않는다.

추가 검증: 관련 규칙·파일·최신 목록 회귀 43개 통과, 전체 TypeScript 검사 통과. 블랙잭 30핸드를 실제로 진행해 마지막 무승부와 경기 종료·재시작을 확인했다. 보험·더블·스플릿 A·S17·서렌더와 목표 달성, 지뢰 동시 버튼·잘못된 깃발·사용자 지정, 야구 3→6자리·26문자·복사·메모·320px·가로 화면 입력도 통과했다.

운영 빌드 검증을 위해 기존 API route의 공유 helper·상수 export를 정리했다. 3D 프로젝트 직렬화·워크플로 함수는 일반 서버 모듈로 옮겨 사용처를 유지했으며 요청·응답·과금 동작은 바꾸지 않았다. 영상 오디오 회귀 6개도 통과했다. 분리한 같은 prompt 체크아웃의 운영 빌드가 통과하고 실제 모달 16개 조합에서 카드 잘림·가로 넘침 없음, 정보/닫기 동작을 확인했다.

포장 캐릭터는 몸 위에서 고개를 내미는 자세, 방향을 돌려도 보는 얼굴, 개별 깜빡임과 배치 소리로 개선했다. 뒤줄 얼굴이 앞줄에 가리지 않게 하고 바닥 높이를 맞췄다. 합치기는 서로 다른 기본 털색도 같은 품종임을 알 수 있게 숫자 목걸이를 사용한다. 시소는 높이와 다이빙 범위에 맞춰 카메라가 따라가고 발로 버티는 동작을 제공한다. 넓은 지뢰판의 네이티브 좌우 스와이프도 확인했다.
