# 고양이 캐릭터 게임 아이디어 80선

2026-10-11 조사 및 사용자 요청 기록. 아래 제목은 실제 출시 게임 이름이 아닌 고양이 응용 기획의 가제다. 실제 참고 작품은 문서 끝의 링크에서 확인한다. 한 판의 선택·실패·결과·재도전과 최고 점수 경쟁을 중심으로 만든다.

## 첫 샘플

냥이 충전 점프, 냥이 뒤집기, 냥이 상자 포장을 먼저 구현한다. 7종 품종은 기본 단모 고양이 → 아메리칸 쇼트헤어 → 브리티시 쇼트헤어 → 샴 → 페르시안 → 랙돌 → 메인쿤 순서다. 색·귀·얼굴·털·꼬리로 구별하고, 등장 순서는 게임의 시각적 연출이며 품종의 실제 가치 순위가 아니다.

## 속도 원칙

레벨·층수에 따라 기본 진행 속도가 올라간다. 사용자 속도 배율은 1–2배이며 1배 미만은 UI·저장값·입력 처리 모두에서 허용하지 않는다. 현재 레벨의 기본 속도에 배율을 곱한다. 새 판에서는 레벨이 초기화되며 사용자가 고른 배율은 유지한다.
