캐릭터·이미지·원작 테이블 배치·원작 프로그램은 사용하지 않았다. PLAYLAB의 자체 Canvas 그래픽과 물리 규칙으로 구현했다. 조사에서 가져온 것은 단계 목표, 공략 경로의 변화, 마지막 보너스 모드라는 설계 원리다.

## 실제 규칙

- **씨앗 정원:** 범퍼 3개, 네 GROW 레인, 양쪽 타깃, 플리퍼 2개. 3볼로 시작한다.
- **1,500점:** 범퍼 2개와 스피너가 추가되고 기본 배수가 최소 2배가 된다. 새 범퍼는 1초의 예고 후 공과 겹치지 않을 때 활성화한다.
- **5,000점:** 화면 위쪽에 별도 물리 공간과 플리퍼 2개가 있는 천공 정원이 펼쳐진다. 첫 공을 올려보내고, 이후 SKY LIFT 램프로 재진입한다. 상층에서 빠지면 공을 잃지 않고 아래 정원으로 돌아온다.
- **상층 별 3개:** 서로 다른 별 범퍼 3개를 맞히면 35초의 별빛 축제가 시작된다. 최대 3볼을 유지하며, 빛나는 범퍼를 순서대로 맞히면 잭팟, 6회마다 슈퍼 잭팟이다. 시간이 끝나면 다시 별을 모아 재도전할 수 있다.
- **보조 목표:** GROW 레인 완성으로 최대 5배, 타깃 6개 완성으로 20초 점수 2배, 램프 3회 보너스, 발사 스킬샷, 콤보. 각 볼 시작 9초의 단일 볼 세이브와 과도한 흔들기에 대한 3초 TILT.
- 공을 잃어도 이번 판의 구조와 수집 진행은 유지된다. 3볼을 모두 잃으면 종료하며, 다음 판은 씨앗 정원·0점에서 시작한다. 영구 경험치나 장비 성장은 없다.
- **상층 연습:** 0점으로 열린 상층에서 시작한다. 연습에서는 최고 기록 저장·대기 점수 저장·서버 제출·부모 페이지 점수 메시지를 모두 생략한다. 정식 도전으로 돌아오면 새 라운드 ID와 초기 상태를 사용한다.

## 구현과 검증

- 기존 루나 가든의 검증된 충돌 방식에서 분리한 새 규칙 모듈. 기존 게임 파일과 기록은 변경하지 않는다.
- 240Hz 고정 간격, 층별 충돌 분리, 상층에서의 공 귀환, 새 물체 생성 겹침 방지, 자연 배수 간격, 재시작 초기화, 업그레이드 단발 실행을 테스트한다.
- 정식 시작에서의 입력 시뮬레이션 16회 모두 상층에 도달했으며, 150초 동안 축제 재진입도 확인했다. 무조작의 세 단계는 공이 정상 배수된다. 이 시뮬레이션은 온라인 점수를 제출하지 않는다.
- 썸네일은 실제 확장판 캡처와 규칙 요약으로 구성한다.
