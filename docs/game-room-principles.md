# 게임룸 제작 기준

사용자 요청 반영: 2026-10-08. 기준 게임은 과일 아틀리에와 마카롱 타워. 사용자가 마카롱의 한 판 재미와 최고 점수 경쟁을 승인했다.

- 한 판 안에서 시작·선택·결과가 완결되는 게임을 만든다. 탭·클릭 하나로 이해할 수 있고, 짧게 즐긴 뒤 다시 도전할 수 있어야 한다.
- 반복해도 새로운 판단이 생기게 한다. 무작위 배치, 순서, 한 판 안의 상황과 리듬, 콤보와 위험 선택으로 변주를 만든다.
- 최고 점수와 숫자 순위에 도전하는 재미를 준다. 게임별·사용자별 최고 점수 하나를 표시하며 오늘/이번 주/이번 달/전체는 한국시간으로 집계한다.
- 귀엽고 촉감이 느껴지는 그래픽, 짧은 소리, 합치기·터뜨리기·정확히 쌓기 같은 반응을 만든다. 모바일 터치와 키보드를 지원한다.
- 누적 레벨업·경험치·장비 성장·상시 콘텐츠 공급에 의존하는 구조는 이 게임룸의 방향에 맞지 않는다. 한 판을 새로 시작하면 상태를 초기화하고 최고 기록만 남긴다.

## 추가한 게임

루나 가든 핀볼: 달빛 식물원 테마의 3볼 플리퍼 핀볼. 청록 유리, 황동 레일, 꽃 범퍼, 크롬 공, 고가 오비트 램프를 Canvas로 직접 그린다. 240Hz 고정 간격으로 회전 플리퍼의 표면 속도와 공·레일·범퍼·공끼리 충돌을 처리한다. LUNA 레인 4개는 배수(최대 5배), 옆 타깃 6개는 20초 2배 점수, 오비트 3회는 잭팟과 3볼 멀티볼이다. 각 볼 시작 후 7초에는 한 번의 볼 세이브가 있고, 과도한 흔들기는 3초 TILT를 일으킨다. 방향키/A·D/좌우 Shift, 스페이스 발사, 터치 동시 플리퍼, 포인터 취소·일시정지 입력 해제를 지원한다. 세 볼을 소진하거나 현재 점수로 마무리하면 기존 숫자 랭킹에 연결한다.

햄스터 간식 핀볼: 다섯 번의 드롭으로 간식을 모으는 물리 게임. 쿠키·딸기 연속 수집, 드롭당 두 번의 좌우 흔들기, 움직이는 바구니 착지 보너스를 제공한다. 각 드롭마다 간식과 범퍼 배치를 새로 만들고, 120Hz 충돌 처리와 최대 체류 시간으로 공이 끼어 라운드가 끝나지 않는 상황을 막는다. 원본 플래시 파일이나 그림을 사용하지 않은 자체 Canvas 그래픽·코드다.

펭귄 얼음 소동: 150초·하트 3개로 끝나는 얼음벽 생존 게임. 방향키/WASD/터치 방향 버튼으로 이동하고, 바라보는 방향의 얼음벽을 만들거나 연속으로 깬다. 만든 벽은 15초 뒤 녹는다. 물개는 최단 경로 탐색으로 우회하며, 생선 3초 연속 수집 콤보와 전체 수집 보너스로 점수를 겨룬다. 무작위 배치와 한 판 안의 적 증가만 있고 영구 성장은 없다.

도넛 꽂기: 회전하는 도넛에 토핑을 꽂는 타이밍 게임. 이미 꽂힌 토핑과 충돌하면 한 판을 마치고, 딸기를 맞추면 보너스가 있다. 필요한 토핑을 모두 꽂으면 완성 점수와 다음 도넛으로 이어지며 속도·방향·회전 리듬이 달라진다. 영구 레벨업은 없다.

고양이 다리 건너기: 누른 시간만큼 다리를 늘려 다음 발판까지 고양이를 건너게 한다. 중앙 착지로 PERFECT 콤보를 만들며, 발판 너비와 간격이 매번 바뀐다. 포인터 캡처로 버튼 밖에서 손을 떼어도 입력을 마무리한다. 터치·스페이스 길게 누르기와 방향키 길이 조절·Enter를 지원한다. 일시정지·포인터 취소·창 전환 시 진행 중 입력을 취소한다.

젤리 정원: 7×8 판에서 같은 젤리 무리를 터뜨리는 25턴 퍼즐. 무리 크기에 따라 점수가 커지고, 7개 이상으로 만든 반짝별은 주변과 다른 별을 함께 터뜨린다. 주문 색은 5번마다 바뀌며 연속 색 콤보가 있다. 색뿐 아니라 문양과 키보드 탐색으로 구별한다.

마카롱 타워: 움직이는 마카롱을 탭·스페이스로 놓는 타이밍 게임. 겹친 부분만 남고 삐져나온 부분은 떨어진다. PERFECT 연속 3번마다 폭을 조금 복구하며 한 판 안에서 방향·속도·흔들림이 달라진다. 빗나가면 층수와 점수로 한 판을 마친다.

과일 아틀리에: 과일 합치기를 유지하고 현재 점수로 한 판을 끝내는 ‘이번 기록으로 마무리’를 추가했다.

## 랭킹 연결

- 미등록 내장 게임은 코드 레지스트리로 즉시 플레이할 수 있다. 첫 로그인 점수 제출 시 정해진 내장 ID의 Artifact를 기존 관리자 소유로 등록하고 GamePlay에 기록한다. 같은 URL의 기존 Artifact가 있으면 ID를 유지해 기존 기록을 합친다.
- 점수는 유한한 정수, 대상은 공개·게시 상태인 게임으로 검증한다. 랭킹 점수에는 인증된 Profile이 필요하다. 라운드 ID·게임 ID·사용자 ID로 중복 제출을 방지한다.
- 익명 플레이의 최고 기록은 기기에 남는다. 종료 점수는 보관하고 로그인 후 등록할 수 있다. 저장 실패 시 재시도를 제공한다.
- 게임 아래 숫자 랭킹 패널을 표시한다. 단독 게임 페이지에서도 기록 조회·등록을 제공한다. 로컬 디자인 미리보기에서는 서버 기록을 게시하지 않는다.
- 이미지는 내장 ImageGen 도구로 생성한 patisserie-garden.webp와 코드로 그린 젤리·마카롱으로 구성했다. 배경 생성 프롬프트는 public/games/little-worlds/art-prompts.json의 sweetGames에 기록했다. 새 썸네일은 실제 플레이 화면을 캡처한 이미지다.

## 검증

2026-10-08 추가: 규칙·랭킹·게임 연결 회귀 테스트 37개, 타입 검사·대상 린트 통과. 실제 도넛 토핑 30점, 고양이 PERFECT 120점과 다음 발판·실패·재시작·최고 기록 보존, 포인터 누르고 놓기, 모바일 375px 화면 및 홈페이지 최신 카드 실행을 확인했다. 새 두 게임 그래픽은 Canvas 코드로 그렸으며 썸네일은 실제 실행 화면에서 만들었다.

규칙·랭킹·기존 게임 회귀 및 링크 연결 테스트 28개 통과. 실제 젤리 정원 25번 선택 후 3,240점 종료, 재시작 시 새 판·0점·최고 기록 보존을 확인했다. 마카롱 타워 3층·179점 종료와 재시작을 확인했다. 과일 아틀리에 합치기로 10점을 얻고 해당 점수로 종료하는 경로를 확인했다. 모바일 375px에서 가로 넘침 없이 조작 UI가 표시된다. 실제 DB의 ID 열 타입과 최고점 집계는 읽기 쿼리로 검증했으며 QA용 가짜 사용자·온라인 플레이 기록은 게시하지 않았다.
